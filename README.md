# PRGO ticket booking

A full-stack event ticket booking starter built with Node.js and vanilla HTML, CSS and JavaScript. No external packages are required.

## Run locally

1. Install Node.js 18 or later.
2. In this folder, run `npm start`.
3. Open http://localhost:3000.

The site has sample events, search and category/city filters, sorting, saved favourites, and a booking flow backed by the Node API. Create an account or log in from the top navigation to book tickets and see your bookings. Passwords are stored as salted hashes in `users.json`; bookings are stored in `data.json`. This starter confirms reservations and does not process payments.
